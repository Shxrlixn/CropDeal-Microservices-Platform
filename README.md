# CropDeal-Microservices-Platform

A distributed agricultural marketplace built using Spring Boot Microservices and Angular.

## Features

* JWT Authentication & Authorization
* Farmer Management
* Dealer Management
* Crop Listing
* Crop Purchase Workflow
* Order Management
* API Gateway Routing
* Eureka Service Discovery
* OpenFeign Inter-Service Communication
* Swagger API Documentation

---

## Architecture

Microservices:

* Authentication Service
* User Service
* Farmer Service
* Dealer Service
* Crop Service
* Order Service
* Admin User Management Service
* API Gateway
* Eureka Server

## Database

Each microservice maintains its own database schema:

* authdb
* userdb
* farmerdb
* dealerdb
* cropdb
* orderdb
* adminuserdb

## Key Implementations

* Service Discovery using Eureka
* Centralized Routing using API Gateway
* Secure Login using JWT
* Independent Database per Service
* RESTful APIs
* CRUD Operations
* Distributed Architecture
